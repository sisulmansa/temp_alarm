설정온도에 따란 알람앱 컨셉

1. 기술
1) Cloudflare Workers KV를 연결
2) Cloudflare Workers + GitHub 연동하여 버전관리를 한다.
3) 순수 표준 JavaScript(ES Modules + 웹 표준 API)로 작성한다.
4) 호스팅 방식: Cloudflare Worker 통합형
5) 접근 보안: Worker URL은 주소 비공개로만 운영


2. 기능
1) weather.go.kr 에서 제공하는 공공데이터로 사용자가 있는 지역의 외기온도가 설정온도(섭씨) 이하일때 알람이 울리는 앱이다.
2) 아이폰 화면이 꺼져 있을 때도 울리는 알림이다.
3) + 버튼을 눌러 사용자가 최대 5개의 알람 온도를 설정할 수 있다.
4) 온도 설정시 아이폰의 알람벨에서 선택할 수 있도록 한다.
5) 알람 설정시 알람에 대한 타이틀을 입력할 수 있다.
6) 알람이 울리면 해당 알람의 타이틀을 강조한다.
7) 설정된 알람을 비활성 하여 울리지 않게 할수 있다.
8) 알람이 울릴시간은 21시, 0시, 03시, 06시 이다.
9) 휴무일용 '전체 알람 일시정지(마스터 스위치)' 추가
10) 00시·03시·06시 알림이므로 아이폰(Bark)은 무음·수면 모드를 돌파하는 긴급 알림(critical) + 30초 벨소리(call=1)


3. 디자인 - 
1) 부트스트랩을 이용한 반응형 웹디자인 적용
2) 기존 점검 웹페이지들과 같은 Bootstrap 5.3 + 네이비 헤더(#17324d) + iOS 스타일 토글 스위치 디자인으로 통일

4. 기타
1) 이 앱의 사용자는 본인 1명만 사용 (단일 설정)한다.
2) "서울시 강서구 마곡동" 지역 (기본 근무지 고정) 이다.
3) Cron 실행 시각 선택 (정각) - 21시·00시·03시·06시 정각마다 조건이 맞으면 매회 발송 (정각에 실행하되, 정각 데이터가 아직 없으면 자동으로 직전 시각의 최신 관측 온도를 기준으로 판단)
4) 알람벨 선택 - 기본알람벨로 설정
5) 알람 울림 시 "타이틀 강조" 방식 - 웹 화면 연동: 푸시 알림을 터치해 웹페이지가 열리면, 방금 울린 알람 카드가 상단에 고정되고 붉은 테두리·깜빡임 효과로 강조되며 타이틀이 크게 표시되도록 연결
6) 교대·당직 근무로 개인별 쉬는 날이 다르기 때문에 알람을 개인별로 끄고 켠다.
8) 여러 알람 조건이 동시에 걸릴 때의 처리 방식 - 예를 들어 0℃ 이하, -5℃ 이하, -10℃ 이하 알람 3개를 켜두었는데 현재 외기온도가 -11℃라면 걸린 알람 중 가장 낮은(심각한) 온도 1개만 푸시 발송하고 웹 상단에 강조
9) Cloudflare 스케줄러는 UTC 기준이므로, 한국시간 21시, 00시, 03시, 06시는 설정 파일(wrangler.jsonc)에 UTC 12, 15, 18, 21시로 자동 변환해 반영합니다.
10) 설정이 잘 작동하는지 바로 확인하는 수동 테스트 알림 발송 버튼과, 현재 마곡동 외기온도 즉시 새로고침 버튼을 화면에 넣는다.
11) 푸시를 터치해 웹 화면이 열렸을 때 상단에 고정·깜빡이는 강조 카드에 「확인 완료(강조 해제)」 버튼을 두어, 확인 후 누르면 평상시 목록으로 복귀
12) 기존에 만드신 점검 페이지들처럼 상단 네이비 헤더 우측에 Home 버튼을 넣을지, 그리고 알람이 울려 상단에 강조 카드가 떴을 때 겨울철 새벽 온도순찰 로드맵 페이지로 바로 이동하는 버튼을 함께 넣는다.
13) 처음 앱을 열었을 때 알람 목록을 비워둔다.
14) 본인 1명 전용이 맞다.
